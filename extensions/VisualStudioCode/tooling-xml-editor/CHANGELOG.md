# Changelog

## 0.1.0

- Initial preview: schema-driven completion, hover, and validation for `.xml` and `.xsd` files;
  schema registration through `xmlEditor.schemas` in user or workspace settings and through
  `xsi:schemaLocation`; auto-closing tags; content-preserving formatter; bundled XML Schema
  vocabulary for authoring `.xsd` files; an API for other extensions to supply schemas.
